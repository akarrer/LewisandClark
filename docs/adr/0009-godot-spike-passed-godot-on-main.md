# The Godot spike has passed; Godot becomes `main`

Supersedes ADR-0006. The spike's two tests from ADR-0007 are met — walking Council Bluff is entertaining on scenery and Trail Moments alone, and iterating in Godot works well for AI-assisted development — and every design decision since assumes Godot. `feat/godot-spike` is the playable line and merges into `main`; the Pygame hex game is tagged where it stands and kept in the tree as the port spec for rules not yet carried over. In practice ADR-0006 had already been overtaken — the spike began landing on `main` through pull requests on 19 September — so this records what is already true rather than changing course. Keeping `main` pinned to the Pygame build was meant to preserve a showable build, but it had come to hide the real one instead.
