# Council Bluff is polished to a showcase first, as the template Region

Loop-first was the obvious path: every Slice beat playable, however rough, before polishing any of it. We chose instead to finish Council Bluff to a showcase standard first, on the grounds that the first Region is the template every later one is built from, so getting it right once limits the work later. That only holds if what is polished is reusable, so Council Bluff is first rebuilt as a data-defined Region — a heightmap plus one Region file of named points, Landmarks, Scenarios, species, scatter and river settings — and proved by making a throwaway second Region with no new code.

## Consequences

- Polish has a finish line, because it has no natural end: the Region is done when every system it needs is present, its scenery meets a written standard, and one uncoached twenty-minute playthrough by someone other than the developer holds up. A budget is the backstop.
- Order of work: the data-defined Region, then the simulation and Morning Report, then the Region's content, then characters (modular period clothing on the existing rig), then the playtest. Content reads the simulation, so building content first means building it twice.
